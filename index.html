Note: meshes are simplified to about 1.5M faces for this web viewer; the paper figures and videos use the full-resolution meshes.

Overview

An object generator, redesigned for whole scenes

  • aAdaptive scene chunks. Chunks grow with distance: small ones keep nearby detail, large ones cover distant buildings.
  • bExplicit 2D–3D conditioning. Image features are lifted onto the observed surface, and each voxel knows if it is free, visible, or hidden.
  • cAutoregressive generation. Neighbouring chunks reuse overlapping latents, so new geometry stays consistent with the scene.
